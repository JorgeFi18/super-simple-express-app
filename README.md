# Mini API en Express.js

Este es un pequeño proyecto de API hecho con Express.js que permite consultar usuarios por medio de rutas y parámetros. El proyecto incluye la funcionalidad de obtener un solo usuario o un rango de usuarios por su índice en una lista.

## Requisitos
- Node.js (versión 14 o superior)

## Instalacion

1. Clona este repositorio en tu máquina local.
```bash
https://github.com/JorgeFi18/super-simple-express-app.git

cd super-simple-express-app
```

2. Instala las dependencias necesarias con npm
```bash
npm install
```

3. Crea un archivo .env en la raíz del proyecto y define el puerto en el que deseas ejecutar la aplicación:

```bash
PORT=3000
```

## Ejecución
Para ejecutar el servidor, usa el siguiente comando:

```bash
npm start
```
